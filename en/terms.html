Article 1 — Service Definition

maPocket is a mobile application developed to enable individual users to quickly track credit card, loan, and recurring expense information. The user manually enters values from their bank app ("Snapshot" / "Snap-Sync" philosophy); the app does not connect directly to any bank and does not request bank passwords or API access.

maPocket is a local-first application: your financial data is stored only on your device and is not stored on any server we operate.

maPocket is NOT accounting software, a tax advisory service, a banking intermediary, financial advice, or an official record-keeping system.

  • Accounting service

5.2. Backup Passphrase Liability

When the backup feature is used, backup files are encrypted on the device with a passphrase set by the user (AES-256-GCM encryption, PBKDF2 key derivation with 100,000 iterations). This passphrase is not transmitted to our servers, not known by us, not stored by us, and cannot be recovered under any circumstances. If the passphrase is lost, the backup file cannot be opened and its contents become inaccessible. The Data Controller / Developer cannot be held liable under any circumstances for data loss arising from this situation.

In the backup creation flow, an explicit warning is shown about safe storage of the passphrase, and the user must confirm that they have read and understood this warning.
